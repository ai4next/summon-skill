# 对抗精炼（Adversarial Refine）

> 保真度评分卡告诉你人格得多少分，对抗精炼告诉你**分数丢在哪一行**。它不重新打分，只交一份可机械执行的补丁候选清单。位置：Phase 4 保真度验证**之后**、Phase 6 交付**之前**，两个攻击者并行开火、互不可见。

## 一、两个攻击者

| | 攻击者 | 猎物 |
|---|---|---|
| A | **保真度攻击者** | 档案里查无实据的编造特质；`gaps` 没映射进「诚实边界」；立场偏离档案「核心骨架」 |
| B | **可用性攻击者** | 「角色扮演规则」的漏洞；不可执行的「表达DNA」条目（形容词冒充规则）；空转的 Agentic Protocol 研究维度；缺失的 Fallback 分支 |

两者**必须并行 spawn、互不可见**。串行会让 B 读到 A 的结论，双方收敛到同一批问题上，覆盖面直接减半。攻击者**只读**人格文件，不写——发现的问题一律走补丁清单，由人（或主 agent）裁定后落地。攻击者自己动手改人格，等于把「发现」和「处置」合并，无法审计。

**两个攻击者正好各守一层**：A 盯 🧠 认知层（档案一致性 / 立场一致性），B 盯 🎭 人格层（风格辨识度 / 表达DNA 可执行性）。
**只派 A** 会漏掉「立场全对但读起来像通用助手」的产物；**只派 B** 会漏掉编造特质。两层都要有人攻。

## 二、四个守卫（本文件的核心）

### 守卫 1：必须交补丁

每条攻击**必须**同时交齐三样：

| 要件 | 内容 |
|------|------|
| **before / after 文本** | 人格文件里的原句 + 改写后的句子（删则 after 为空并标「删除」） |
| **命名的评分卡维度** | 必须是六维之一：立场一致性 / 风格辨识度 / 边缘诚实度 / 来源透明度 / 结构完整度 / 档案一致性 |
| **被攻击行号** | `SKILL.md` 的精确行号（或 `references/` 下文件的路径 + 行号） |

三样缺任意一样 → 该条**直接丢弃**，不进入补丁清单，只在「已丢弃」区留一行审计记录。

**为什么**：一条不带补丁的攻击是**意见**，不是发现。意见无法被验证（改哪句？改成什么？），也无法被机械应用（落到哪个维度？动哪一行？）。只有「原句 → 新句 + 维度 + 行号」这种形式，才能让裁定者不看攻击者的脸色、只看 diff 就能拍板。这是把主观不满转成可执行工单的唯一办法。

### 守卫 2：攻击者必须拿到 ground truth

保真度攻击者的 prompt 里**必须**给到源档案 `distilled/<slug>/DISTILLATE.md`（frontmatter + 正文 + `gaps`），且允许其逐条回查。

**为什么**：没有 ground truth，攻击者只能攻击**风格**——它会发现人格里每条主张都「找不到出处」（因为它手里没有人格所本的那份档案），于是把「我核对不了」误判为「凭空编造」，要求把整份人格的心智模型与启发式批量删掉。这不是保真，是**保真度通缩**：一份忠于档案的人格会被攻击到只剩空壳，而真正编造的特质反而因为「看起来和别的一样」而蒙混过关。攻击者手里有 `DISTILLATE.md`，才分得清「无对应条目」和「我没去对」。

### 守卫 3：只许删改，不许新增断言

精炼只能**删**（删编造特质、删空转维度、删不可执行规则）或**改**（把形容词改写为可计数规则、把未映射的 `gaps` 补写进诚实边界、把漂移的立场拉回档案骨架），**绝不允许新增档案里没有的立场或特质**。

| ✅ 允许 | ❌ 禁止 |
|---|---|
| 删掉档案里查无实据的一条心智模型 | 给心智模型补一条「档案没写但更完整」的 |
| 把「幽默风趣」改写为「极短句优先，先给结论不铺垫」 | 新增一条档案里没有的表达特征 |
| 把 `gaps` 漏掉的第 3 条补写进诚实边界 | 替角色生成为一个他没表过的立场 |
| 把空转的研究维度改写为可落到工具动作的 query 方向 | 给 Agentic Protocol 加一个通用的「搜索相关信息」 |

**为什么**：新增内容是**在不动质量的前提下刷分**的标准手法——补两段设定，结构完整度看起来更满了、立场看起来更全了，但人格的保真度一寸没长。这条守卫同时堵死反模式 #1「把真人当传声筒替本人表态」：档案没覆盖的，正确动作是写进诚实边界，不是拿训练语料填。

### 守卫 4：不做「必须提升否则回滚」的评分闸门

本 pass 的产出是**补丁候选清单**，交给用户/主 agent 裁定，**不重新打分、不设回滚阈值**。

**为什么**：单个 LLM 的评分有 **±5-10 分噪声**，而本流程自己的规则是「**迭代上限 2 轮**，两轮后仍不达标就在诚实边界标注薄弱维度、交付当前最优版本」——这条规则已经承认了「分数不总是能被推上去」。若再叠一道「精炼后必须提分否则回滚」的闸门：

- 分数抖动 +6 分时 → 闸门放行，其实什么都没修好，纯噪声被当成进步
- 真实的修补撞上 -7 分的噪声 → 闸门回滚，把唯一做对的一处改回原样

一半概率放过噪声，一半概率杀掉真修复。更糟的是，闸门会诱导攻击者去**踩红线换分**：档案一致性只要出现编造特质就是 0 分、**直接判 D，不论总分**；立场一致性 <12 也一票最高判 C。为了让分数好看而给角色补立场，正好从这两个红线上碾过去。**质量信号从来不来自同一次评分的涨跌，而来自跑第二个独立评分 agent。** 精炼结束后要判断有没有变好，就重跑 Phase 4 保真度评分卡，对照两次分维度得分——而不是让攻击者兼裁判。

## 三、Spawn prompt 模板

### A · 保真度攻击者

```
你的任务：对 <slug>-persona 的 SKILL.md 做保真度对抗审查。你是攻击者，只找问题，不修复。

你可以读：~/.claude/skills/<slug>-persona/SKILL.md（及其 references/）、
源档案 distilled/<slug>/DISTILLATE.md（frontmatter + 正文 + gaps）。
档案是你的唯一 ground truth，逐条回查是你的义务。

只猎三类目标：
1. 编造特质——人格里出现档案查无对应条目、又未标「（推断）」的主张
2. gaps 漏映射——档案 frontmatter 的 gaps 有一条没出现在人格「诚实边界」段
3. 立场漂移——人格的立场陈述与档案「核心骨架」方向不一致

每条攻击必须交齐四件，缺一件则该条作废：
- before：被攻击的原句（逐字）
- after：改写后的句子（纯删除则写「删除」）
- 维度：立场一致性 / 风格辨识度 / 边缘诚实度 / 来源透明度 / 结构完整度 / 档案一致性 之一
- 行号：SKILL.md 的精确行号

铁律：
- 不许新增断言。只许删、只许改。绝不许给角色补立场、补特质、补经历。
- 档案里没有 ≠ 编造：先回 DISTILLATE.md 查。查过确无对应且未标（推断），才按第 1 类报。
- 不要提「整体感觉」「建议加强」这类无行号的意见——会被直接丢弃。
- 你不打分，不改人格。产出交回主 agent。
```

### B · 可用性攻击者

```
你的任务：对 <slug>-persona 的 SKILL.md 做可用性对抗审查。你是攻击者，只找问题，不修复。

你可以读：~/.claude/skills/<slug>-persona/SKILL.md（及其 references/）、
源档案 distilled/<slug>/DISTILLATE.md（核对研究维度是否真的源自心智模型）。

只猎四类目标：
1. 角色扮演规则的漏洞——未规定第三人称禁令、未规定超边界时的拒绝方式、可被用户一句话绕开
2. 不可执行的表达DNA——用形容词代替规则（「幽默风趣」「深入浅出」），不可计数、不可证伪
3. 空转的 Agentic Protocol——研究维度是抽象名词，落不到工具动作
4. 缺失的 Fallback——防漂移三件套（STOP / EXIT TRIGGER / 角色硬规则）有缺口，或触发词没列全

每条攻击必须交齐四件，缺一件则该条作废：
- before：被攻击的原句（逐字）
- after：改写后的句子（纯删除则写「删除」）
- 维度：立场一致性 / 风格辨识度 / 边缘诚实度 / 来源透明度 / 结构完整度 / 档案一致性 之一
- 行号：SKILL.md 的精确行号

铁律：
- 不许新增断言。改写表达DNA时，只许把已有特征改成可执行规则，不许发明新特征。
- 改写研究维度时，只许从该人格已有的心智模型反推，不许引入档案里没有的模型。
- 不要提「整体感觉」「建议加强」这类无行号的意见——会被直接丢弃。
- 你不打分，不改人格。产出交回主 agent。
```

## 四、补丁清单输出格式

落盘为 `~/.claude/skills/<slug>-persona/REFINE.md`（人格目录归 summon 所有，见 `artifact-format.md` 第四节）。

```markdown
# 对抗精炼补丁候选清单

**人格**：<slug>-persona @ 源档案 DISTILLATE.md sha256 3a71…（version N）| 日期：YYYY-MM-DD | 轮次：1/2
**攻击者**：A 保真度 / B 可用性（独立双 agent，互不可见）

| # | 攻击者 | 维度 | 行号 | 攻击理由 | before | after | 处置 |
|---|--------|------|------|---------|--------|-------|------|
| 1 | A | 档案一致性 | 34 | 该心智模型档案无对应条目，未标（推断） | … | 删除 | 采纳 |
| 2 | A | 边缘诚实度 | 52 | 档案 gaps 第 2 条未进诚实边界 | … | … | 采纳 |
| 3 | B | 风格辨识度 | 71 | 表达DNA 为形容词，不可执行 | 幽默风趣 | 极短句优先，先给结论 | 采纳 |
| 4 | B | 结构完整度 | 96 | EXIT TRIGGER 触发词不全 | … | … | 存疑：档案未列全退出词 |

## 已丢弃（缺要件，仅留审计）
- [A] 行 18：只有理由，无 before/after → 丢弃
- [B] 行 88：未命名维度 → 丢弃

## 裁定摘要
采纳 N 条 · 驳回 M 条 · 存疑 K 条
**未改动断言数量：0**（精炼只删改，不新增）｜**红线自查**：无一条补丁给角色新增立场或特质
```

**处置**三选一：`采纳` / `驳回` / `存疑`。驳回必须写理由——驳回理由本身是下一轮的输入。

## 五、迭代上限与红线

**最多 2 轮**，与 Phase 4 的迭代上限一致：第 1 轮 A/B 并行开火 → 补丁清单 → 裁定落地；第 2 轮对落地后的人格重跑 A/B，**只处理新暴露的问题**，不重复攻击已驳回项；第 2 轮后无论清单多长都停手。

**为什么是 2 轮**：精炼的终点是「诚实标注薄弱维度的人格」，不是「看起来完美的人格」。第 3 轮开始，攻击者会开始制造**无补丁可交的攻击**（把已驳回项换个说法再报一遍），或诱导编辑者新增立场来「补完整」——后者直接撞上守卫 3，并且**一票否决**：档案一致性 = 0（存在编造特质）→ 不论总分**直接判 D**；立场一致性 <12 → 最高判 C。**特别危险**：攻击者**绝不能推着人格去增加立场以显得更完整**——「这个角色对 X 没表态，人设不够立体」不是一条有效攻击。档案没覆盖的，正确动作是保留结构性沉默、写进诚实边界（见 `distillation-framework.md` 第六节与 `persona-forge.md` 第六件套）。两轮后仍有问题，在诚实边界中标注薄弱维度，交付当前最优版本。

## 六、质检清单

- [ ] A/B 是**并行 spawn** 的两个独立 agent？互不可见？
- [ ] 攻击者 prompt 里给了 `DISTILLATE.md`（守卫 2）？
- [ ] 每条攻击都带 before/after + 命名维度 + 行号？缺要件的已进「已丢弃」区（守卫 1）？
- [ ] 全部 after 文本里，**没有一条新增立场或特质**？（守卫 3）
- [ ] 本 pass **没有**重新打分、没有设回滚阈值（守卫 4）？
- [ ] `gaps` 逐条在诚实边界核对过？漂移的立场已拉回「核心骨架」？
- [ ] 驳回项都写了理由？第 2 轮只处理新问题、未重报已驳回项？轮次 ≤2？
- [ ] 两轮后仍不达标的维度已写进诚实边界？
- [ ] 要判断精炼是否有效，已另跑**第二个独立评分 agent** 重跑保真度评分卡？
