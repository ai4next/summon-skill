# 对抗精炼（Adversarial Refine）

> 四轴评分卡告诉你人格得多少分，对抗精炼告诉你**分数丢在哪一行**。它不重新打分，只交一份可机械执行的补丁候选清单。
>
> 位置：**P7**——在 **P6 验真（四轴）**之后、**P8 交付**之前，两个攻击者并行开火、互不可见。
>
> **上位公理：`design-philosophy.md` 公理 2（溯源）与公理 4（自洽）。**

## 一、两个攻击者

| | 攻击者 | 猎物 |
|---|---|---|
| A | **溯源攻击者** | ground truth 里查无实据的**编造**；**假推断**——标了 `src: inferred`，但推导链**点不出所用的公理 / 心智模型 / 启发式**；**缺口未映射**——信息缺口 / 闭包边界没进「诚实边界」 |
| B | **认知攻击者** | **矛盾**——两条主张在**同一情境**下给出**相反判断**，且都没提对方（**不是**张力）；**伪造的张力**——人格自称有某对张力，但 `AXIOMS.md` 的内在张力表里没有那一行；不可执行的「表达DNA」（形容词冒充规则）；空转的 Agentic Protocol 研究维度；缺失的 Fallback 分支；**校准放宽**——`CALIBRATION.md` 里有条目**扩大**了行为 |

两者**必须并行 spawn、互不可见**（串行会让 B 读到 A 的结论，覆盖面减半）；攻击者**只读**人格文件，不写——发现的问题一律走补丁清单，由人（或主 agent）裁定后落地。

**各守一层**：A 盯 🧠 认知层的**根**（溯源推导链、缺口映射），B 盯 🧠 认知层的**内部一致性**（矛盾 vs 张力）与 🎭 人格层（表达DNA 可执行性）、⚖️ 运行层（`CALIBRATION.md` 收窄纪律）；只派一个必漏另一半。

> **分工边界**：A 问「这条主张指得回公理吗？」，B 问「这些主张之间立得住吗？」——同一个「无根」归 A、「自相矛盾」归 B，不要两边都报。

## 二、四个守卫（本文件的核心）

### 守卫 1：必须交补丁

每条攻击**必须**同时交齐三样：

| 要件 | 内容 |
|------|------|
| **before / after 文本** | 人格文件里的原句 + 改写后的句子（删则 after 为空并标「删除」） |
| **命名的评分卡轴** | 必须是**四轴之一**：生成力 / 自洽性 / 辨识度 / 溯源 |
| **被攻击行号** | `SKILL.md` 的精确行号（或 `references/` 下文件的路径 + 行号） |

三样缺任意一样 → 该条**直接丢弃**，不进入补丁清单，只在「已丢弃」区留一行审计记录。

**补丁若动的是溯源指针，另附 `src:`（改前 → 改后）。** 它**不替代**三样中的任何一样——`src:` 让「假推断」这类攻击有可落地的修法（把点不出名字的 `src: inferred` 补成能点名公理 / 模型 / 启发式的推导链，或整条删掉），而不只是改措辞。见 §四 的 `src:` 列。

**为什么**：一条不带补丁的攻击是**意见**，不是发现——无法验证（改哪句？改成什么？），也无法机械应用（落到哪个轴？动哪一行？）。只有「原句 → 新句 + 轴 + 行号」才能让裁定者只看 diff 拍板。

### 守卫 2：攻击者必须拿到 ground truth

攻击者的 prompt 里**必须**给到 ground truth，**按材料类型取**：

| 材料类型 | ground truth |
|---------|-------------|
| **合成型** `archetype`（这个人不存在） | 公理集 **`references/AXIOMS.md`**（人格目录里那份），允许逐条回查 |
| **实录型** `real` | 用户提供的材料（源材料 `MATERIAL.md`：frontmatter + 正文 + 信息缺口） |
| **原作型** `fictional` | 原作设定资料 |

**为什么**：没有 ground truth，攻击者只能攻击**风格**——手里没有人格所本的那份根，就会把「我核对不了」误判为「凭空编造」，要求把整份人格的心智模型与启发式批量删掉（**溯源通缩**）。有公理集（或材料），才分得清「无对应条目」和「我没去对」。

> **合成型不是「没有 ground truth」，是 ground truth 换成了公理集**（公理 2）；它是三条**平等**主路径之一，不是降级——不得因为「没有 `MATERIAL.md`」就断定整份人格是编造的。

### 守卫 3：只许删改，不许新增断言

精炼只能**删**（删编造特质、删空转维度、删不可执行规则）或**改**（把形容词改写为可计数规则、把未映射的缺口补写进诚实边界、把并列的**矛盾**改写成显式**张力**或删掉一条），**绝不允许新增公理集 / 材料里没有的立场或特质**。

| ✅ 允许 | ❌ 禁止 |
|---|---|
| 删掉 ground truth 里查无实据的一条心智模型 | 给心智模型补一条「材料没写但更完整」的 |
| 把「幽默风趣」改写为「极短句优先，先给结论不铺垫」 | 新增一条材料里没有的表达特征 |
| 把漏掉的缺口第 3 条补写进诚实边界 | 替角色生成为一个他没表过的立场 |
| 把空转的研究维度改写为可落到工具动作的 query 方向 | 给 Agentic Protocol 加一个通用的「搜索相关信息」 |
| 把并列的**矛盾**改写成显式**张力**，或删掉其中一条 | 把「人格自己知道并说出来」的**张力**当矛盾删掉 |
| 把放宽边界的 `CALIBRATION.md` 条目改回收窄动作，或整条撤销 | 用 `CALIBRATION.md` 给角色补一条新立场、放宽诚实边界、删掉反模式 |

**为什么**：新增内容是**在不动质量的前提下刷分**的标准手法——补两段设定，辨识度、溯源看起来更全了，但根一寸没长。这条守卫同时堵死反模式 #1「把真人当传声筒替本人表态」。

> ⚠️ **用 `CALIBRATION.md` 放宽行为，与新增断言同罪。** 它改的是运行记录，不是出厂快照，
> 但效果一样：让角色说出闭包外的话。
> **判据是收窄测试**：「这条校准让这个人在**更多**问题上说话，还是在**更少**问题上说话？」
> **更多 → 越界，驳回**（`roster-format.md` §5.4）。
> 攻击者 B **必须**把 `CALIBRATION.md` 一并纳入攻击面。

### 守卫 4：不做「必须提升否则回滚」的评分闸门

本 pass 的产出是**补丁候选清单**，交给用户/主 agent 裁定，**不重新打分、不设回滚阈值**。

**为什么**：单个 LLM 的评分有 **±5-10 分噪声**，而本流程已承认「**迭代上限 2 轮**，两轮后不达标就标注薄弱轴、交付当前最优版本」。再叠一道「精炼后必须提分否则回滚」的闸门，只会一半概率放过噪声、一半概率杀掉真修复，还会诱导攻击者**踩红线换分**：**溯源 S = 0（存在编造或假推断）就是直接判 D，不论总分**；**自洽性 C <15 最高判 C**；**辨识度 D <12 最高判 C**（红线 canonical source：`fidelity-scorecard.md` §五）。**质量信号从来不来自同一次评分的涨跌，而来自跑第二个独立评分 agent**——精炼后要判断有没有变好，就重跑 **P6** 四轴评分卡、对照两次**逐轴**得分，而不是让攻击者兼裁判。

#### 4.1 但「重跑一次再对照」承受同样的噪声——所以要写清判据

上一条否决了评分闸门，但**重跑对照承受同样的噪声**——用一次 ±7 的测量比另一次 ±7 的测量，分不出「+6 是真进步」还是「抖动」。所以**必须补一条判定规则**，否则「重跑对照」只是一句听起来更严谨的废话。

**只认两类信号，其余一律不下结论**：

| 信号 | 判据 | 为什么可信 |
|------|------|-----------|
| **跨红线** | 从「触红线」变为「不触」或反之（S=0 / C<15 / D<12 / G<12，`fidelity-scorecard.md` §五） | 红线是**离散**的：跨过去就是跨过去了，不受 ±10 的连续噪声支配 |
| **多评分者中位数** | **≥2 个评分 agent 独立跑**，取各轴中位数；中位数差 **> 噪声带**（默认 `NOISE_BAND`=10） | 中位数对单点噪声不敏感；n≥2 时，同向偏移才算信号 |

**其余情况如实说「在噪声带内，本次对比不构成趋势」**——这正是 `eval_record.py compare`
已经在做的事（`--noise`，默认 10），评分卡应当与它对齐，而不是另立一套。

> **`compare` 的退出码 2 就是「拒绝给结论」**：调用方据此判断「不要据此下结论」。
> 精炼后的对比走同一条路径：**给不出趋势就说给不出**，不要用「感觉好多了」补位。

## 三、Spawn prompt 模板

### A · 溯源攻击者

```
你的任务：对 <slug>-persona 的 SKILL.md 做溯源对抗审查。你是攻击者，只找问题，不修复。

你可以读：~/.claude/skills/<slug>-persona/SKILL.md（及其 references/）、
~/.claude/skills/<slug>-persona/references/AXIOMS.md（合成型的公理集）、
~/.claude/skills/<slug>-persona/CALIBRATION.md（若存在；运行侧覆盖层，只许收窄）、
源材料 `MATERIAL.md`（实录型 / 原作型的 ground truth；frontmatter + 正文 + 缺口）。

ground truth 按材料类型取：合成型 = 人格目录里的 references/AXIOMS.md；实录型 / 原作型 = 源材料 / 原作设定。
ground truth 是你的唯一基准，逐条回查是你的义务。

只猎三类目标：
1. 编造——人格里出现 ground truth 查无对应条目、又未标「（推断）」的主张
2. 假推断——标了 src: inferred，但推导链点不出所用的**公理 / 心智模型 / 启发式**。
   公理 2 的推导义务：点不出名字的推断 = 编造，与第 1 类同罪。
3. 缺口未映射——ground truth 的信息缺口 / 闭包边界有一条没出现在人格「诚实边界」段

每条攻击必须交齐四件，缺一件则该条作废：
- before：被攻击的原句（逐字）
- after：改写后的句子（纯删除则写「删除」）
- 轴：生成力 / 自洽性 / 辨识度 / 溯源 之一
- 行号：SKILL.md 的精确行号
若补丁动的是溯源指针，另附 src:（改前 → 改后）；它不替代上面四件。

铁律：
- 不许新增断言。只许删、只许改。绝不许给角色补立场、补特质、补经历。
- ground truth 里没有 ≠ 编造：先回公理集（或材料）查。查过确无对应且未标（推断），才按第 1 类报。
- 不要提「整体感觉」「建议加强」这类无行号的意见——会被直接丢弃。
- 你不打分，不改人格。产出交回主 agent。
```

### B · 认知攻击者

```
你的任务：对 <slug>-persona 的 SKILL.md 做认知对抗审查。你是攻击者，只找问题，不修复。

你可以读：~/.claude/skills/<slug>-persona/SKILL.md（及其 references/）、
~/.claude/skills/<slug>-persona/references/AXIOMS.md（公理集：判断「矛盾还是张力」的依据）、
~/.claude/skills/<slug>-persona/CALIBRATION.md（若存在；运行侧覆盖层，只许收窄）。

只猎六类目标：
1. 矛盾——两条主张在**同一情境**下给出**相反判断**，且都没提对方。
   判据（`design-philosophy.md` §4.1 冲突三分）：**这个人格自己知不知道那个冲突？**
   知道并说出来 = 张力（资产，**不要报**）；不知道、两句并列摆着 = 矛盾（要报）。
2. **伪造的张力**——人格在「我自己也没想清楚的」段自称有某对张力，
   但 **`AXIOMS.md` 的内在张力表里没有这一行**。事后补的张力 = 编造（公理 2.3），要报。
3. 不可执行的表达DNA——用形容词代替规则（「幽默风趣」「深入浅出」），不可计数、不可证伪
4. 空转的 Agentic Protocol——研究维度是抽象名词，落不到工具动作
5. 缺失的 Fallback——防漂移三件套（STOP / EXIT TRIGGER / 角色硬规则）有缺口，或触发词没列全
6. 校准放宽——CALIBRATION.md 里有条目扩大了这个人的说话范围（新增立场 / 放宽诚实边界 /
   删除反模式）。判据是收窄测试：「这条校准让他在更多问题上说话，还是更少？」更多 → 越界。

每条攻击必须交齐四件，缺一件则该条作废：
- before：被攻击的原句（逐字）
- after：改写后的句子（纯删除则写「删除」）
- 轴：生成力 / 自洽性 / 辨识度 / 溯源 之一
- 行号：SKILL.md 的精确行号（若攻击的是 CALIBRATION.md 的条目，写该文件的路径 + 行号）
若补丁动的是溯源指针，另附 src:（改前 → 改后）；它不替代上面四件。

铁律：
- 不许新增断言。改写表达DNA时，只许把已有特征改成可执行规则，不许发明新特征。
- 改写研究维度时，只许从该人格已有的心智模型反推，不许引入公理集 / 材料里没有的模型。
- **不要报张力。** 「人格自己知道并说出来」的冲突是资产；把它当缺陷报掉，等于删掉这个人的深度。
- 校准只许改**收窄**，不许把条目改成放宽（那等于用运行记录给角色补立场）。
- 不要提「整体感觉」「建议加强」这类无行号的意见——会被直接丢弃。
- 你不打分，不改人格。产出交回主 agent。
```

## 五、迭代上限与红线

**本 pass 在 P7**：**P6 验真（四轴）**出分之后、**P8 交付**之前。

**最多 2 轮**（与 **P6** 一致）：第 1 轮 A/B 并行开火 → 补丁清单 → 裁定落地；第 2 轮对落地后的人格重跑 A/B，**只处理新暴露的问题**，不重报已驳回项；第 2 轮后无论清单多长都停手。

**为什么是 2 轮**：终点是「诚实标注薄弱轴的人格」，不是「看起来完美的人格」。第 3 轮起，攻击者会制造**无补丁可交的攻击**（把已驳回项换个说法再报一遍），或诱导编辑者新增立场——后者直接撞上守卫 3（红线见 `fidelity-scorecard.md` §五，守卫 4 已说明为何这道闸门不能靠单次评分把守）。

**攻击者绝不能推着人格增加立场以显得更完整**——「这个角色对 X 没表态，人设不够立体」不是有效攻击。材料没覆盖的，正确动作是保留结构性沉默、写进诚实边界（`design-philosophy.md` 公理 5、`persona-forge.md`）；用 `CALIBRATION.md` 放宽边界同理（`roster-format.md` §5.4）。两轮后仍有问题，在诚实边界中标注薄弱轴，交付当前最优版本。
