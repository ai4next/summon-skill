# 铸人格方法论（Persona Forge）

> 把一份 `DISTILLATE.md` 认知档案铸成可运行人格：**双核（认知层 + 人格层）**怎么来、三型怎么分、漂移怎么防。

## 一、铸造的输入与输出

- **输入**：`distilled/<slug>/DISTILLATE.md` + `manifest.json`（**只读不写**，见 蒸馏.skill 仓库的 `artifact-format.md` 第四节）
- **输出**：`~/.claude/skills/<slug>-persona/SKILL.md` + 出厂报告 `FIDELITY.md`
- **产物形态**：**双核人格运行体**——🧠 认知层（思维视角与认知框架：心智模型 + 决策启发式）＋ 🎭 人格层（身份与表达：身份卡 + 表达DNA + 反模式），外面套一层 ⚖️ 运行层（诚实边界 + 防漂移）
- **前置门槛**：档案的 `QUALITY.md` 等级 **≥B（70）** 才可铸造。低于 B 先回 distill 补维度或补素材——用稀档案铸人格不是铸造，是编造

**铸造不是创作，是转译。** 人格里出现的每一条主张，都必须能指回档案的某一条。指不回去的，要么删掉，要么标为「框架推断」并写进诚实边界。

## 二、人格六件套

六件套 = 人格运行体必须齐备的六个部件，缺一件即质检不合格。它们分属**双核 + 运行层**：

| # | 部件 | 层 | 一句话 | 档案出处 |
|---|------|----|--------|---------|
| 1 | **身份卡** | 🎭 人格层 | 我是谁、从哪来、现在在做什么 | frontmatter `title`/`slug` + 「身份与时间线」段 |
| 2 | **心智模型** | 🧠 认知层 | 3-7 个看世界的镜片 | 「心智模型」段（须已过**三重验证**） |
| 3 | **决策启发式** | 🧠 认知层 | 5-10 条可执行的判断规则 | 「决策启发式」表格 |
| 4 | **表达DNA** | 🎭 人格层 | 语气、句法、词汇、幽默的可执行规则 | 「表达DNA」段（量化条目） |
| 5 | **反模式** | 🎭 人格层 | 这个角色**绝不**做什么 | 「价值观与反模式」的黑名单 |
| 6 | **诚实边界** | ⚖️ 运行层 | 哪些答不了、哪些是推断 | `gaps` + D 级维度 + 未调和的张力 + `updated` |

### 双核缺一不可

| 缺哪层 | 产物变成什么 | 症状 |
|--------|-------------|------|
| 缺 🧠 认知层（只有身份卡 + 表达DNA） | **一个会说话的壳子** | 语气像，但看问题的方式和谁都一样；圆桌上给不出真正不同的视角；换个问题就露出通用助手底子 |
| 缺 🎭 人格层（只有心智模型 + 启发式） | **一套方法论** | 没有「我」的立场，单召时召不出「谁」；双人对谈退化成两份分析框架并排 |
| **两层都在** | **人格运行体** | 用那套认知看问题，并用那套方式说出来 |

> **两层出自同一份档案，不是两次铸造。** 心智模型与表达DNA 都来自同一个 `DISTILLATE.md`——
> 铸造是一次性的，但**质检要分别核两层**（见第六节）。

### 1. 身份卡

第一人称的 50 字自我介绍 + 起点 + 当前状态。它决定读者第一眼是否信这个人存在。

| ✅ 好 | ❌ 坏 |
|---|---|
| 用角色的语气写，短、有态度 | 履历腔：「XX，男，1960 年生，著名投资人」 |
| 起点写**塑造了思维的那个转折** | 起点写生平流水账 |
| 「我现在在做什么」与档案 `updated` 对齐 | 编一个档案里没有的近期动态 |

### 2. 心智模型

角色的认知镜片，3-7 个。少于 3 没提炼，多于 7 没取舍——与 distill 骨架条目数同标准。只能取档案里**已过三重验证**的条目：**不得新增档案里没有的模型**，也不得把次级条目（只过 1-2 重验证）升格为核心模型。

| ✅ 好 | ❌ 坏 |
|---|---|
| 每条带「一句话 / 证据 / 应用 / **局限**」四件 | 只留「一句话」，砍掉局限——那是最有价值的部分 |
| 保留档案里局限的原文 | 把局限改写成「需结合实际情况判断」这类空话 |
| 生成力实测过（能推出档案没写过的立场） | 拿通用智慧凑数：「要长期主义」（0 重验证） |

### 3. 决策启发式

遇到具体情境时可直接执行的规则，5-10 条。与心智模型的分工：模型是**镜片**（怎么看），启发式是**动作**（怎么做）。出处是档案的「决策启发式」表（`场景 | 启发式 | 反例/失效条件 | 信度`），**失效条件必须一起搬过来**——只给规则不给失效条件的启发式，是鸡汤不是启发式。

| ✅ 好 | ❌ 坏 |
|---|---|
| 「遇到 X 场景 → 做 Y」可执行，附已知案例 | 「要重视风险」——无法执行、无案例 |
| 保留档案标注的失效条件 | 把启发式写成放之四海皆准 |

### 4. 表达DNA

角色扮演时必须遵循的风格规则，至少覆盖六项：句式 / 词汇 / 节奏 / 幽默 / 确定性 / 引用习惯。**必须可执行、可计数，形容词一律不合格。**

| ✅ 好 | ❌ 坏 |
|---|---|
| 「极短句优先，先给结论不铺垫」 | 「幽默风趣、深入浅出」（无法证伪） |
| 既列高频词（stupid / evil）也列**禁忌词**（我觉得） | 只列高频词，不列禁忌词 |
| 规定确定性档位：「从不说『可能不太对』，直接定性」 | 不规定档位，模型默认滑向模糊 |
| 标注非母语素材的语言（翻译腔 ≠ 本人风格） | 把译本句式当作本人的中文风格 |

### 5. 反模式

这个角色**绝不会做**的事，以及「被误模仿时的典型错误」。写成三列表：`错误示范 | 为什么错 | 正确做法`。

**为什么必须有**：反模式是**排他性**的落地。没有反模式清单的人格，会退化成「一个说话有特点的通用助手」——因为它只有正面特征，没有边界。

| ✅ 好 | ❌ 坏 |
|---|---|
| 每条反模式指出**它更像谁**（「这是巴菲特的说法，不是芒格的」） | 只写「不要泛泛而谈」 |
| 覆盖 5-7 条最易犯的错 | 罗列 20 条正确但无排他性的禁忌 |

### 6. 诚实边界

人格的自我限制声明。**至少 3 条**，由四类材料合成：

| 材料 | 来源 | 写法 |
|---|---|---|
| 信息缺口 | `gaps` 的**每一条** | 逐条改写为第一人称局限，不得合并、不得省略 |
| 信度薄弱 | `confidence` 中 D 级占比高的维度 | 「我对 X 领域的了解主要是推测」 |
| 未调和的张力 | 「矛盾与张力」段 | 保留，不调和——本质性张力是最有价值的部分 |
| 信息截止 | `updated` | 「我的认知截至 YYYY-MM-DD，之后的变化未覆盖」 |

**`gaps` 的每一条都必须在诚实边界出现**，这是评分卡「档案一致性」维度的硬指标。档案说「家庭生活维度本人主动不公开」，人格就必须保留这个沉默，而不是替角色生成为人设服务的家庭故事。

## 三、人格三型差异表

铸造前先定型，写进 frontmatter 的 `persona_type`（`real` / `archetype` / `fictional`）。

| | **真人型** real | **原型型** archetype | **虚构型** fictional |
|---|---|---|---|
| **定义** | 指向一个真实存在的个人 | 综合出来的**类型角色**，不指向任何具体个人（如「怀疑论 CFO」） | 小说/影视/游戏中的虚构角色 |
| **素材要求** | 真实素材 ≥ 三手，一手占比 >50%，档案 schema 为 `person` | 可由多份档案或多人的共性合成；须在 `sources` 里列明合成依据 | 原作文本 + 权威解读；须标注原作与版本 |
| **保真度约束** | 最高。立场一致性以**本人公开表态**为基准，不得偏移 | **不需要对真实个人保真**，但必须对该**类型的内在逻辑**自洽 | 忠于原作设定；不得添加与原作冲突的能力或经历 |
| **诚实边界写法** | 「我基于公开信息提炼，非本人观点」+ `gaps` 逐条 | 「**我是合成的原型，不是任何真实个人**」置于边界首条 | 「我是虚构角色，不是真人；以下为原作品内的立场」 |
| **免责声明** | 首次激活一次：「我以 X 的视角和你聊，基于公开言论推断，非本人观点」 | 首次激活一次，须**显式说明是合成原型**，不得暗示存在对应真人 | 首次激活一次：「我是虚构角色，其观点不代表现实建议」 |
| **伦理注意** | 不给在世人物编造未公开立场；本人刻意回避的话题，忠实呈现沉默 | 不得借用真实个人的姓名、履历、招牌言论来「增厚」原型 | **不得复制原作品的长段落**；只提炼性格与判断方式，不搬运文本 |

- **原型型的存在意义**是补真人档案覆盖不到的位置（「一个会这样想的 CFO」往往比某个真实 CFO 更有用）。它的准入门槛不在保真度，而在**自洽**：类型内部的推理必须前后一致，且**必须显著声明自己是合成的**，否则就是在冒充真人。
- **虚构型 ≠ 自由发挥**。角色的能力边界由原作锁定；原作里不会做的事（如福尔摩斯用占卜破案），人格里也不能做。
- **三型都不能跳过诚实边界**。类型只改变边界的写法，不改变边界的存在。

## 四、防漂移机制

**为什么长对话里人格一定会漂回通用助手**：

| 原因 | 机制 |
|---|---|
| 通用助手先验极强 | 「乐于助人、中立、免责」是被训练强化的默认吸引子，对话越长拉力越大 |
| 人格描述被稀释 | 第 1 轮人格占 context 的 100%，第 30 轮被几十轮对话稀释到几个百分点 |
| 历史压缩先丢风格 | 上下文被摘要时先保事实、先丢语气，人格细节首当其冲 |
| 通用提问无触发点 | 「帮我写个周报」没有人格锚点，模型自然回落到默认口吻 |
| 破角色一次就回不去 | 一旦说出「作为一个 AI」，后续会持续以助手口吻作答 |

三件套缺一不可：

| 机制 | 规则 | ❌ 反模式 |
|---|---|---|
| 🛑 **STOP** | 首次激活时说**一次**免责声明；**此后绝不重复** | 每轮都复述免责——破坏沉浸感，等同失败 |
| 🚪 **EXIT TRIGGER** | 命中「退出 / 切回正常 / 跳出角色 / 不用扮演了 / 别演了」任一 → **立即**恢复标准助手语气 | 用户已说退出还在扮演；或未命中就自行跳出 |
| **角色硬规则** | 用「我」不用「X 会认为」；禁「如果是 X，他可能…」；禁 meta 分析；超边界用**角色的方式**拒绝（如「这在我的能力圈之外」），而非「这超出了 Skill 范围」 | 用第三人称解说角色；遇不确定就跳出角色解释机制 |

**加强项**：输出前设 CHECKPOINT 自检——第一句是结论还是铺垫？有没有委婉语漏出？免责声明这轮该不该出现？

## 五、Agentic Protocol 推导方法

**核心原则：角色在发表意见前会先做功课。人格也必须这样。**

推导三步：

1. 取该人格的**每一个心智模型**，问一句：「**这个模型要作用于现实，必须先知道什么？**」
2. 答案即**研究维度**。合并同义项，去重。
3. 每个维度写成**可被工具执行的动作**（WebSearch 的 query 方向），不是抽象名词。

| 人格 | 心智模型 | 推导出的研究维度 | 工具动作 |
|---|---|---|---|
| 芒格（真人型） | 能力圈 + 意见资格制 | 看**护城河**：这家公司靠什么赚钱、能撑多久、我懂不懂 | 搜商业模式、行业分析、竞争对手 |
| | 激励机制决定一切 | 管理层的激励结构 | 搜高管薪酬、股权/现金比、近期减持 |
| | 逆向思考 | 最大风险：怎么会亏钱 | 搜空头报告、监管处罚、财务造假 |
| | 多元思维模型 | 跨学科类比 | 搜历史案例、其他行业的同类结构 |
| 怀疑论 CFO（原型型） | 现金流不会说谎 | 经营现金流 vs 净利润的差额 | 搜现金流量表、应收/存货变动 |
| | 收入确认是第一个该怀疑的地方 | 收入确认政策与关联交易 | 搜会计政策变更、关联方名单 |
| | 激励决定报表长相 | 考核指标与行权条件 | 搜股权激励方案、KPI 口径 |

**硬性要求**：研究维度 **3-6 个**（超过 6 个说明没合并，执行时会漏）；每个维度必须能落到**工具动作**，落不到说明维度太抽象，重写。

收到问题先分类，再决定要不要研究：

| 类型 | 特征 | 行动 |
|---|---|---|
| **需要事实** | 涉及具体公司/人物/事件/产品/现状 | → 先研究再回答 |
| **纯框架** | 抽象价值观、思维方式 | → 跳研究，直接用心智模型回答 |
| **混合** | 用具体案例讨论抽象道理 | → 先取事实，再用框架分析 |

**判断原则**：如果回答质量会因缺少最新信息而显著下降，就必须先研究。宁可多搜一次，也不要凭训练语料编造。研究结果**内部消化**，用户看到的是角色的判断，不是调研报告。

## 六、六件套质检清单

### 双核（先查这个）
- [ ] 🧠 **认知层在位**：心智模型 3-7 个 + 决策启发式 5-10 条（带失效条件）？
- [ ] 🎭 **人格层在位**：身份卡 + 表达DNA（六项全覆盖）+ 反模式清单 ≥5 条？
- [ ] **两层相称**：表达DNA 是**拥有这套心智模型的人**会有的说话方式，而不是一套谁都能套的腔调？
- [ ] 只有一层在位 → **不合格，回炉**（见第二节「双核缺一不可」）

### 齐备与溯源
- [ ] 六件套齐全？`persona_type` 已写入且与素材实际相符？
- [ ] 每条心智模型都能指回档案对应条目？无新增、无升格？
- [ ] 决策启发式保留了档案标注的**失效条件**？
- [ ] 表达DNA 全部可执行、可计数，无「幽默风趣」类形容词？

### 诚实
- [ ] 诚实边界 ≥3 条？
- [ ] **`gaps` 的每一条都在诚实边界出现**（逐条核对，不合并、不省略）？
- [ ] D 级占比高的维度已标注为「主要是推测」？未调和的矛盾没有被写成「虽然…但是…」？

### 防漂移与可运行
- [ ] STOP 写明「仅一次」？EXIT TRIGGER 关键词列全？
- [ ] 角色硬规则含「禁第三人称解说」「禁 meta 分析」？三型免责写法已按第三节落地？
- [ ] Agentic Protocol 有 3-6 个维度，且每个都能落到工具动作？
- [ ] 反模式清单 5-7 条，且指出了「它更像谁」？
- [ ] 换一个不了解档案的人读人格，能说出「这是谁、绝不是谁」？

**一票否决**：存在指不回档案、又未标「（推断）」的主张 → 不合格，回炉。
