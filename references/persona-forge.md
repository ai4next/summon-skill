# 铸人格方法论（Persona Forge）

> **提炼 → 显式公理集 → 放大。** 把**用户提供的信息**铸成一个可运行人格：
> 六件套怎么来、材料类型怎么分、公理集怎么立、推导闭包怎么落地、漂移怎么防——都在这里。
>
> **上位公理：`design-philosophy.md`。** 本文件是「怎么铸」的 canonical source；
> 「为什么这么铸」的判据与射程在公理文件里，不在这里重复。
> 概念归属见 `design-philosophy.md` §四：**一个概念只在本文件定义一次**，别处只写指针。
>
> **本文件 §三 同时是「公理集（`AXIOMS.md`）的格式、验收与模板」的 canonical source**——
> 怎么写、怎么验、长什么样，三件事都在那一节，别处只写指针。

## 一、输入与输出

**输入永远是用户提供的信息**——区别不在「有档案 / 没档案」，而在**三种平等的材料类型**：

| 材料类型 | `persona_type` | 用户给的是什么 | 前置门槛 |
|---------|---------------|--------------|---------|
| **实录型** | `real` | 真实人物的档案 / 文献 / 公开言论 | 材料自带 `QUALITY.md` 时，等级 **≥B（70）** 才可铸造（无评级则可铸） |
| **原作型** | `fictional` | 虚构作品的原作设定 | 原作文本 + 权威解读在位，须标注原作与版本 |
| **合成型** | `archetype` | 只有主题 / 一句口述——**这个人不存在** | 无档案门槛；与用户**当场立定**公理集 |

- **可审计的中间产物**：**显式公理集**（3-7 条不可再分的基本立场），落在 `references/AXIOMS.md`。
  它是 ground truth，也是**最便宜的返工点**——改 5 条公理比改 400 行人格便宜得多（公理 2）。
- **输出**：`~/.claude/skills/<slug>-persona/SKILL.md` + 同目录 `references/AXIOMS.md`
  （**自包含、可迁移**）+ 出厂报告 `FIDELITY.md`
- **产物形态**：**双核人格运行体**——🧠 认知层（心智模型 + 决策启发式）＋ 🎭 人格层（身份卡 + 表达DNA + 反模式），
  外面套一层 ⚖️ 运行层（诚实边界 + 防漂移）
- **前置门槛只对实录型 / 原作型**：材料自带 `QUALITY.md` 且 < B → 先补素材，或改走合成型、与用户当场立公理集。
  **没有 `QUALITY.md` 不等于材料不合格**（可选落盘约定见 `roster-format.md` §一）。
  **用稀档案铸实录型不是铸造，是编造**

**三入口脚手架**（`scripts/forge_scaffold.py`；三选一，都通向同一个产物）：

```bash
# 实录型 / 原作型：材料是任意文件或目录
python3 scripts/forge_scaffold.py <材料路径> \
    --out ~/.claude/skills/<slug>-persona --type real --slug <slug>
# 零文件：材料只在对话里（口述 / 粘贴文本）
python3 scripts/forge_scaffold.py --source-desc "口述 2026-09-24，他聊了成本观" \
    --slug <slug> --out ~/.claude/skills/<slug>-persona --type real
# 合成型：给公理集
python3 scripts/forge_scaffold.py --axioms <AXIOMS.md 路径> --out ~/.claude/skills/<slug>-persona
```

**铸造不是创作，是转译——但允许推导。** 人格里出现的每一条主张，必须能**指回 ground truth 的某一条**
（材料条目，或某条公理），或能**按推导闭包从公理 / 心智模型 / 启发式推出**（§五，公理 2）。
指不回去也推不出来的，要么删掉，要么写进诚实边界。

## 二、人格六件套（认知层在前）

> **先分清两件事**：**六件套是概念模型**（六个必须齐备的**能力**），
> **`persona-template.md` 的段落清单是产物 schema**（十几个段落）。两者不是一一对应。
>
> **顺序就是权重**：前两件是 🧠 **认知层，主产物**；后四件服务于它们（公理 1）。

| # | 部件 | 层 | 一句话 | 从哪来 |
|---|------|----|--------|--------|
| 1 | **心智模型** | 🧠 **认知层（主产物）** | 他怎么看世界（3-7 个镜片） | 由公理集**放大**：每条公理展开成一个镜片 |
| 2 | **决策启发式** | 🧠 **认知层（主产物）** | 他怎么判断（5-10 条，带失效条件） | 由公理集**复合**：多条公理作用于具体情境 |
| 3 | **身份卡** | 🎭 人格层 | 让他能说「我是谁」 | 材料时间线 / 原作设定 / 立定的合成身份 |
| 4 | **表达DNA** | 🎭 人格层 | 他怎么说话（六项可执行规则） | **拥有这套心智模型的人会有的说话方式** |
| 5 | **反模式** | 🎭 人格层 | 他绝不做什么 | 公理集的**否定面** + 闭包边界 |
| 6 | **诚实边界** | ⚖️ 运行层 | 他做不到什么 | 信息缺口逐条 + 结构性沉默 + **闭包边界** |

**六件套 → 产物段落的映射**（模板里的段落比六件套多，多出来的不是「第七件套」，
而是**让六件套真的跑得住**的支撑段落）：

| 六件套 | 对应产物段落 | 支撑段落（不属六件套，但不可删） |
|--------|-------------|------------------------------|
| 心智模型 | 核心心智模型 | 公理集（认知层的根） |
| 决策启发式 | 决策启发式 | 回答工作流（Agentic Protocol）· CHECKPOINT 自检 |
| 身份卡 | 身份卡 · 智识谱系 | 使用说明 |
| 表达DNA | 表达DNA | 示例对话 |
| 反模式 | 价值观与反模式 | 反例黑名单 · 失败模式与 Fallback 树 |
| 诚实边界 | 诚实边界 | 角色扮演规则（STOP / EXIT / 硬规则）· 附录信息源 |

> 「公理集」段是**根**，不属六件套中的任何一件——但认知层的两条都从它推导出来。
> 它也是 §三 的产物：**公理集不确认，不许放大**。

**关键约束**：「角色扮演规则」「表达DNA」「诚实边界」「反例黑名单」**四段不可删**——
它们是双核在长对话里不塌的物理保证。

**六件套 ✅/❌ 速查**（各件判据的完整表述见对应小节）：

| 部件 | ✅ 好 | ❌ 坏 |
|------|------|------|
| 心智模型 | 每条带「一句话 / 证据 / 应用 / **局限**」四件；保留材料里局限的原文；**生成力实测过**；带 `src:` 溯源指针 | 只留「一句话」砍掉局限；把局限改写成「需结合实际情况判断」这类空话；拿通用智慧凑数；无指针、无法回查 |
| 决策启发式 | 「遇到 X 场景 → 做 Y」可执行，附已知案例；保留材料标注的失效条件；带 `src:` 指针 | 「要重视风险」——无法执行、无案例；把启发式写成放之四海皆准；无指针 |
| 身份卡 | 用角色的语气写，短、有态度；起点写**塑造了思维的那个转折**；当前状态与 ground truth 的时间信息对齐 | 履历腔：「XX，男，1960 年生，著名投资人」；起点写生平流水账；编一个材料里没有的近期动态 |
| 表达DNA | 「极短句优先，先给结论不铺垫」；既列高频词（stupid / evil）也列**禁忌词**（我觉得）；规定确定性档位；标注非母语素材的语言 | 「幽默风趣、深入浅出」（无法证伪）；只列高频词，不列禁忌词；不规定档位，模型默认滑向模糊；把译本句式当作本人的中文风格 |
| 反模式 | 每条反模式指出**它更像谁**（「这是巴菲特的说法，不是芒格的」）；覆盖 5-7 条最易犯的错 | 只写「不要泛泛而谈」；罗列 20 条正确但无排他性的禁忌 |

### 人格层服务于认知层（公理 1）

**先问「他怎么想」，再问「他怎么说」。** 表达DNA 不是一套谁都能套的腔调，
而是**拥有这套心智模型的人**会有的说话方式。

| 顺序 | 产物 | 判定 |
|------|------|------|
| 先有认知，再长出表达 | 人格运行体 | ✅ 换一套心智模型，说话方式就跟着变 |
| 先定腔调，再填认知 | 一个会说话的壳子 | ❌ 语气像，但看问题的方式和谁都一样 |

**「两层相称」是硬约束**：表达DNA 与心智模型不匹配 = 不合格。

### 双核缺一不可

| 缺哪层 | 产物变成什么 | 症状 |
|--------|-------------|------|
| 缺 🧠 认知层（只有身份卡 + 表达DNA） | **一个会说话的壳子** | 语气像，但看问题的方式和谁都一样；换个人格，说法几乎不变 |
| 缺 🎭 人格层（只有心智模型 + 启发式） | **一套方法论** | 没有「我」的立场，召不出「谁」；听起来像两份分析框架并排 |
| **两层都在** | **人格运行体** | 用那套认知看问题，并用那套方式说出来 |

> **两层出自同一份 ground truth，不是两次铸造。** 铸造是一次性的，但**质检要分别核两层**（见 §八）。

### 2.1 心智模型 · 🧠 认知层（主产物）

角色的认知镜片，3-7 个。少于 3 没提炼，多于 7 没取舍。

- **实录型 / 原作型**：只取材料里**证据充分**的条目（已过三重验证）；
  **不得新增材料里没有的模型**，也不得把次级条目升格为核心模型
- **合成型**：每条模型必须能点名它**由哪条公理放大**而来（`src: AXIOMS.md#A2`）——
  没有材料兜底，模型与公理的对应关系就是它的全部依据

**每条模型必须带溯源指针**（公理 2 的机器可读形式）：

```markdown
### 模型1: 现金流优先
- **src**: AXIOMS.md#A1                 # 或 MATERIAL.md#心智模型/现金流优先 @A
- **一句话**：…
- **证据**：…
- **应用**：…
- **局限**：…
```

`src` 取值二选一：**ground truth 条目 ID**（可定位），或 **`inferred`**
（推断——此时「证据」行必须写出推导链并**点名**，见 §五.2）。

**生成力是模型的验收标准，不是加分项**（公理 3）：自问
**「用这个镜片看一个公理集没提过的问题，会得到什么公理集里没有的判断？」** 答不出 → 这个模型没铸成（P6 探针必失败）。

### 2.2 决策启发式 · 🧠 认知层（主产物）

遇到具体情境时可直接执行的规则，5-10 条。与心智模型的分工：模型是**镜片**（怎么看），启发式是**动作**（怎么做）。
出处是材料的「决策启发式」表（`场景 | 启发式 | 反例/失效条件 | 信度`），或**由公理集复合推出**。
**失效条件必须一起搬过来**——只给规则不给失效条件的启发式，是鸡汤不是启发式。

### 2.3 身份卡 · 🎭 人格层

第一人称的 50 字自我介绍 + 起点 + 当前状态。它决定读者第一眼是否信这个人存在。

### 2.4 表达DNA · 🎭 人格层

角色扮演时必须遵循的风格规则，至少覆盖六项：句式 / 词汇 / 节奏 / 幽默 / 确定性 / 引用习惯。
**必须可执行、可计数，形容词一律不合格。**

**表达DNA 必须与心智模型相称**（公理 1 的硬约束，`design-philosophy.md` 公理 1）：
一个「逆向思考、能力圈」的人和一个「现金流不会说谎」的人，说话方式本来就该不同。

### 2.5 反模式 · 🎭 人格层

这个角色**绝不会做**的事，以及「被误模仿时的典型错误」。写成三列表：`错误示范 | 为什么错 | 正确做法`。
**反模式是排他性的落地**：只有正面特征、没有边界的人格会退化成「一个说话有特点的通用助手」。

### 2.6 诚实边界 · ⚖️ 运行层

人格的自我限制声明。**至少 3 条**，由**六类**材料合成：

| 材料 | 来源 | 写法 |
|---|---|---|
| 信息缺口 | 材料的 `gaps` / 「该有而没给」的**每一条** | 逐条改写为第一人称局限，不得合并、不得省略 |
| **结构性沉默** | 材料里**显式标注**的沉默条目 | 「这类问题我不表态，这是我的一贯立场」——**不是缺口，不要补** |
| **闭包边界** | 公理集的「闭包边界」段（§三.4） | 「我在 X / Y / Z 领域**本质无立场**」——**永不补**（公理 5） |
| 信度薄弱 | `confidence` 中 D 级占比高的维度 | 「我对 X 领域的了解主要是推测」 |
| 未调和的张力 | 公理集的「内在张力」段（§三.3） | 保留，不调和——本质性张力是最有价值的部分 |
| 信息截止 | `updated` / 认知截止日 | 「我的认知截至 YYYY-MM-DD，之后的变化未覆盖」 |

**`gaps` 的每一条都必须在诚实边界出现**，这是质检「溯源」维度的硬指标。
材料说「家庭生活维度本人主动不公开」，人格就必须保留这个沉默，而不是替角色生成为人设服务的家庭故事。

> ⚠️ **结构性沉默 / 闭包边界与 `gaps` 必须分开写。** `gaps` 是「该有而没给」→ 要回材料侧补；
> 结构性沉默与闭包边界是「主动不公开 / 本质无立场」→ **永远不补**（公理 5）。
> 把两者混在一起，会让人以为沉默也是缺口，进而为刻意沉默的人编造立场——判 0 分的行为。

## 三、立公理集（全流程的根）

> **无论输入是什么，都先提炼出一份显式公理集。** 这是 P3 🔴 检查点，也是本方法论的中心。
> **公理集立不住，后面全是白工；公理集立对了，放大是机械的。**
> 判据与射程见 `design-philosophy.md` 公理 2——本节只讲**怎么立、怎么验、怎么存**。

### 3.1 公理集是什么

- **3-7 条不可再分的基本立场**，写成一份 `AXIOMS.md`。它是这个人格的 **ground truth**。
- 放在**人格目录自己的** `references/AXIOMS.md` → 人格目录因此**自包含、可迁移**；
  `forge_scaffold.py --axioms <AXIOMS.md>` 会把它**复制进去**，哈希取自副本。
- frontmatter 里 **`source_axioms` 是相对人格目录的路径**（惯例 `references/AXIOMS.md`），
  **`source_axioms_sha256`** 是它的哈希（漂移检测依据，脚本自动写入，**不要手填**）。
- **公理集是最便宜的返工点**（`design-philosophy.md` §2.1）：确认检查点设在公理集上，不设在成品上。**用户确认前不许放大。**

**三型的公理集从哪来**（公理 2.1）：

| 材料类型 | 公理集从哪来 |
|---------|-------------|
| **实录型** | 从档案 / 文献 / 公开言论里**提炼**出他反复依据的那几条基本立场 |
| **原作型** | 从原作设定里**提炼**角色的价值排序 |
| **合成型** | 与用户**当场立定**这几条立场——「不存在」不等于「无根」 |

**完整模板见 §3.6。** 两点形状约束（`forge_scaffold.py` 按此解析并预填心智模型小节标题，别改）：

- 公理表必须是 `| **A1** | **立场** | 理由 | 代价 |` 四列，**编号与立场都要加粗**——
  脚本才能抽出 `(A1, 立场)` 并预置 `- **src**: AXIOMS.md#A1`
- 「闭包边界」「推演预览」两段必须存在，且段名照写（P6 探针的排除集靠它定位）

### 3.2 七条验收标准

| 标准 | 判据 | 怎么验 |
|------|------|--------|
| **不可再分** | 每条公理不能用集内其他公理推出 | 试着用 A2…Ak 推出 A1：推得出 → A1 是**定理**，删掉，或并入推出它的那条 |
| **有代价** | 每条公理都答得出「**遵守它会在什么情境下让你吃亏 / 什么会推翻它**」 | 答不出代价的公理是套话（「要重视风险」），删掉。**这是正向检验，比「不可再分」可靠得多**（§3.2.1） |
| **够用** | 3-7 条 | 少于 3 撑不起一个视角；多于 7 说明没提炼。删到只剩互相独立的 |
| **互相有张力** | 至少一对公理在**极端情境**下冲突 | 找一对「都想要、但拿不全」的公理（§3.3）；一条张力都找不到 → 人格会太「顺」。**张力通常是「有代价」的副产品** |
| **可推导** | 用它跑生成力探针时，能推出公理集里没写过的具体判断 | **当场推**：取一条公理作用到一个**公理集没讨论过的具体情境**上，**把新判断写出来，随公理集一起交确认**（P3 🔴）——不是留到 P6 才验 |
| **可重构** | 用它**重推得回材料里已有的判断** | **重构测试**：取一条这个人做过、公理集没明写的判断，只用公理集 + 闭包规则推一遍（§3.2.2）。推不回 → 公理集漏了东西，回 P2。**合成型见 §3.2.3** |
| **声明合成** | 合成型的首条必须是「不对应任何具体个人」 | 查 `AXIOMS.md` 开头的声明块（公理 5） |

**七条全过 → 交用户确认 → P4 放大。** 有一条不过 → 回 P2 重新提炼，**不要带着缺陷放大**。

> **「可推导」与「可重构」方向相反，两个都要做**（`design-philosophy.md` §2.5）：
> 前者测**解压**能走多远，后者测**压缩**有没有损。
> 只做可推导，一份漏了关键立场的公理集照样能推出一两个新判断；只做可重构，一份把材料抄短的索引也能过。

#### 3.2.1 为什么必须有「代价」这一条

启发式要求**失效条件**（§2.2：只给规则不给失效条件的启发式是鸡汤，`fidelity_check.py` 会核）。
公理是**比启发式更强的**主张——启发式不过是公理的复合产物。**更强的主张反而免于举证，不成立。**

| | 「不可再分」（负向） | 「有代价」（正向） |
|---|---|---|
| 怎么判 | 试着用别的公理推出它 | 问「遵守它，你会在哪儿吃亏」 |
| 可靠性 | **无法机械判定，极易伪造**——靠人读 | **有具体产出**——答不出就是套话 |
| 副产品 | 无 | 代价之间必然相撞 → **张力**（§3.3） |

**这一列同时替代了「不可再分」与「互相有张力」两条标准的检验方式。**

#### 3.2.2 重构测试怎么做

1. 从材料里挑一条这个人**实际做过**的判断（越具体越好），确认**公理集没明写**它
2. 只用公理集 + 闭包规则（`design-philosophy.md` §2.2 的四条）推一遍，**点名**用了哪几条
3. 推得出来 → 压缩无损 ✅；推不出来 → **公理集漏了东西**，回 P2

**重构测试的结果与「当场推」的结果一起落盘进 `AXIOMS.md` 的「推演预览」段**（§3.5 模板）——
它同时是 P6 生成力探针的**排除集**（§3.7）。

#### 3.2.3 合成型的重构测试怎么做

**问题**：重构测试的对象是「**材料里**已有的判断」，但合成型**没有材料**。
若不重新定义，这一条对合成型是空的——而空的标准会被悄悄填成编造。
示例人格曾这样写：「材料里的判断：曾否决一个『毛利率 60%、回收期 30 个月』的方案」——
一个 `archetype` 说「材料里」有什么，**本身就是公理 2 意义上的编造**。

**合成型的重构对象是三选一**（按可用性排序）：

| 对象 | 什么时候能用 | 怎么写 |
|------|-------------|--------|
| **用户在场时说过的一条判断** | P2 对话里用户描述过「我要一个会否决 XX 的人」 | 「用户在 P2 说过：他会否决回收期超 30 个月的方案」 |
| **立定公理集时当场产生的判断** | 与用户对话中立出公理集之后，用户对某个具体情境表过态 | 「立公理集时用户认可：免费用户占比 95% 的 SaaS 不该继续投增长」 |
| **公理集自身的重推** | 前两者都没有（纯主题输入） | 明说「本型无外部材料，重构测试退化为**内部一致性检查**：由 A2+A4 重推 A3 的应用，不产生新断言」 |

**不允许的写法**：凭空写一条「材料里的判断」。合成型没有材料，这句话就是编的。

> **由此，合成型的「可重构」比实录型弱——这一点要如实说。**
> 它的 ground truth 是当场立定的公理集（§四），所以它测的确实是**内部一致性**而非外部保真。
> 这不是缺陷，但不能把「自洽」读成「有根」（`fidelity-scorecard.md` §四）。


### 3.3 内在张力（公理集必须自带）

> 公理集必须自带至少 **1 对张力**，否则人格会太「顺」——太顺的人格推不出有棱角的判断。
> **张力的判据（矛盾 vs 张力）在公理 4，本文件不重复**——这里只讲怎么把它**设计出来**。

**门槛分两级，别混**（这两级的数值 canonical source 是 `scripts/_spec.py` 的
`TENSION_MIN_GATE` / `TENSION_MIN_TARGET`）：

| 级别 | 对数 | 谁在管 | 不达标会怎样 |
|------|------|--------|-------------|
| **硬门禁** | **≥1** | `fidelity_check.py`（静态，FAIL） | 出厂门直接不过——1 对都没有说明公理集里缺一条真正有代价的立场 |
| **质量目标** | **≥2** | 评分卡「张力在位」的满分条件 | 静态检查只给 WARN，评分卡拿不到那 10 分的满分 |

**为什么是两级而不是一个数**：门槛太松会放过「顺得像 PPT」的人格，
门槛太硬又会把「确实只有一对真张力」的诚实产物挡在门外。
所以**能出厂**（≥1）与**够好**（≥2）是两件事，如实分开报。

| 张力 | 冲突的公理 | 表现（人格自己怎么描述这个冲突） |
|------|-----------|------------------------------|
| **[张力名]** | A? vs A? | 「我知道 X，但我也知道 Y——我说不清那条线在哪」 |

**写法要求**：张力必须**由两条真公理的冲突产生**，不能是「既严谨又灵活」这类形容词对。
写不出来 → 说明公理集里缺了一条真正有代价的立场。

### 3.4 闭包边界（本质无立场的领域）

> **闭包边界 = 这个人格「本质无立场」的领域**，是**设计的一部分**，不是事后补的免责声明。
> 对**合成型**尤其关键：**必须在立公理集时就写进闭包边界**，不能等被问到了再打补丁（公理 5）。

| 领域 | 性质 | **由哪条公理决定** | 处置 |
|------|------|------------------|------|
| [领域] | **结构性沉默**——本质无立场 | **A?** | 明确划界，不展开；**不因被追问而生成立场** |
| [领域] | **伦理红线** | **A?**（或「伦理，非公理」） | 永不给操作建议，只谈方法（公理 6） |
| [领域] | 信息缺口 | — | 明说「我手上没有真实信息」，运行时先查——**不属于回材料侧补** |

**「由哪条公理决定」这一列是硬性的**（`design-philosophy.md` §5.2：沉默是形状，不是空白）——
公理定义了他**答什么**，边界定义了他**不答什么**；列不出公理的条目就不是这个人的形状。

> **列不出公理的边界条目 = 通用免责声明，不是这个人的形状。**
> 「我不谈政治 / 宗教 / 医疗」和这个人的认知毫无关系，**任何人格都能贴上去**，因此它**不是**闭包边界。
> 有形状的边界长这样：*怀疑论 CFO 不谈技术架构 / 人事管理，**因为**这些领域不归约到 A1（现金流）。*
> 这条列同时堵死一条刷分路径：**用通用免责清单冒充闭包边界**。

**三型的闭包边界从哪来**：

| 材料类型 | 闭包边界从哪来 |
|---------|--------------|
| 实录型 | 材料里**显式标注**的沉默条目（主动不公开）+ 伦理红线 |
| 原作型 | 原作设定的能力 / 认知边界 + 伦理红线 |
| **合成型** | **与用户当场设计**：哪些领域这个人格本质无立场 + 伦理红线 |

> ⚠️ **闭包边界与信息缺口必须分开写。** 缺口是「该有而没给」→ 回用户补 / 写进诚实边界；
> 边界是「本质无立场」→ **永远不补**（公理 5）。混在一起，会逼着为刻意沉默的主体编造立场。
> 边界写进产物时**单列一段**，不要塞进「信息缺口」列表里。

### 3.5 完整范例：怀疑论 CFO（合成型）

```markdown
# 立场公理集 · 怀疑论 CFO
> **本合成人格不对应任何具体个人。** 五条公理如下，其余立场全部由此推导。

| # | 公理 | 为什么不可再分 | 遵守它的代价 |
|---|------|--------------|-------------|
| **A1** | **现金流可信度高于会计利润** | 财务判断的终点；利润可被口径塑造 | 错过「现金流难看但模式成立」的早期公司 |
| **A2** | **单位经济学不成立时，规模只会放大亏损** | 定义「增长是否值得」的判据 | 抢规模的行业里永远不敢下注 |
| **A3** | **基准率优先于个案叙事** | 定义「该信什么」的判据 | 错过真正的异常值 |
| **A4** | **风险必须被量化为下行绝对值** | 定义「风险」一词的含义 | 无法量化的风险被当成不存在 |
| **A5** | **口径决定行为，口径变化优先于数字变化** | 定义「怎么看一个数字」的起点 | 滑向「先怀疑口径」而停在原地 |

**内在张力**：保守 vs 增长（A1/A2）· 信数据 vs 疑数据（A4/A5）· 反战略亏损 vs 承认投入期（A2/现实）。**推演预览**：当场推——免费用户占 95% 的 SaaS 不该投增长（由 A2）✅；重构测试——重推回「否决回收期 30 个月的方案」（A4 + A2）✅。
```

**放大映射**：A1–A5 → 心智模型（每条一个镜片，带 `src: AXIOMS.md#A?`）· 公理复合 → 启发式（带失效条件）· 内在张力 → 「我自己也没想清楚的」段 · 闭包边界 → 诚实边界结构性沉默段；**七条验收**（§3.2）逐条过：不可再分 · 有代价 · 够用（5 条）· 有张力（3 对）· 可推导 · 可重构 · 声明合成 ✅。**完整模板见 §3.6**，可运行副本见 `examples/skeptic-cfo-persona/references/AXIOMS.md`。

### 3.7 确认检查点（P3 🔴）

**公理集展示给用户确认，然后才放大。** 展示模板（本文件是公理集格式 / 模板的 canonical source，
六段缺一不可）：

```text
① 合成声明   合成型首行：「本合成人格不对应任何具体个人」（实录型 / 原作型改写为溯源基准）
② 公理表     | 编号 | 立场 | 为什么不可再分 | 遵守它的代价 |
③ 内在张力   至少 1 对：| 张力名 | 冲突的公理 | 本人格怎么描述这个冲突 |
④ 闭包边界   | 领域 | 性质 | 由哪条公理决定 | 处置 |
⑤ 信息缺口   该有而没给，逐条列出；与闭包边界分开写
⑥ 推演预览   当场推（公理集没提过的新情境）+ 重构测试（材料里已有的判断）
```

**字段写法见 §3.6 模板；③ 的对数门槛见 §3.3；④ 的「由哪条公理决定」列是硬性要求。**
用户觉得不对 → 回 P2 重新提炼，**不许「先铸着看，后面再调公理」**——
那等于让 400 行人格悬在一份没被确认的根上。

#### 3.7.1 P3 公理集攻击者（1 个 agent）

**在这里派一个攻击者，是本流程性价比最高的一次 spawn。** 理由：公理集是**最便宜的返工点**
（`design-philosophy.md` §2.1），而 P3 此前只有自查 + 用户点头——自查最不可靠的恰恰是这里：
§3.2.1 承认「**『不可再分』无法机械判定，极易伪造——靠人读**」。

**攻击者只猎四类**（都不需要读 400 行人格，只需读 `AXIOMS.md`）：

| # | 猎什么 | 判据 |
|---|--------|------|
| 1 | **伪造的不可再分** | 试者用**集内其他公理**推出这条：推得出 → 它是定理，该删或该并 |
| 2 | **套话代价** | 把「遵守它的代价」换一条无关公理，这句话还成立吗？成立 = 是套话（§3.2.1） |
| 3 | **伪张力** | 那对「张力」是不是两条真公理在**极端情境**下的冲突？还是「既严谨又灵活」这类形容词对（§3.3） |
| 4 | **无形状的闭包边界** | 每条边界能不能归约到某条公理（A?）？列不出的 = 通用免责声明（§3.4） |

**四条护栏与 P7 一致**（canonical source：`adversarial-refine.md` §二）：
必须交补丁（before/after + 轴 + 行号）· 必须拿 ground truth（这里是公理集本身）·
**只许删改不许新增**· 不做评分闸门。

**产出**：补丁清单直接摆给用户，**与公理集一起在 P3 确认**——而不是等到 P8 才发现根是歪的。
**代价**：1 个 agent。**它拦下的每一次返工，省下的是 P4–P7 的 7–9 个 agent。**

> **攻击者与「用户确认」不是二选一。** 用户点头点的是**方向**（这是不是我想铸的那个人）；
> 攻击者查的是**结构**（这五条立不立得住）。前者用户做不了，后者攻击者做不了。

**展示必须含推演预览**：当场推 1-2 个公理集没写过的判断，再做一次重构测试——只摆抽象立场，用户点头点的是措辞，不是根；推不出新判断的公理集在这里就该被打回。

**推演预览必须落盘**（写进 `AXIOMS.md` 的「推演预览」段，§3.6 模板），并**自动成为 P6 生成力探针的排除集**：P6 探针要的正是「**在闭包内、但公理集未明示**」，落盘即把 P3 的输出与 P6 的题集连上，避免探针退化成记忆测试（`fidelity-scorecard.md`）。

## 四、材料类型差异表（三型）

铸造前先定类型，写进 frontmatter 的 `persona_type`（`real` / `fictional` / `archetype`）。

| | **实录型** `real` | **原作型** `fictional` | **合成型** `archetype` |
|---|---|---|---|
| **定义** | 指向一个真实存在的个人 | 虚构作品中的角色 | 只存在于这次对话里的合成人格，**不指向任何具体个人** |
| **材料要求** | 真实素材 ≥ 三手，一手占比 >50%；自带 `QUALITY.md` 时须 **≥B** | 原作文本 + 权威解读；须标注原作与版本 | 只有主题 / 口述；依据须在 `sources` 列明 |
| **ground truth** | `MATERIAL.md`（+ 由它提炼的公理集） | 原作设定（+ 由它提炼的公理集） | **公理集 `AXIOMS.md`** |
| **溯源基准** | 本人**公开表态** | **原作设定** | **公理集**——不对任何人保真 |
| **诚实边界写法** | 「我基于公开信息提炼，非本人观点」+ `gaps` 逐条 | 「我是虚构角色，不是真人；以下为原作品内的立场」 | 「**我不对应任何具体个人**」置首条 + 闭包边界 |
| **免责声明** | 首次激活一次：「我以 X 的视角和你聊，基于公开言论推断，非本人观点」 | 首次激活一次：「我是虚构角色，其观点不代表现实建议」 | 首次激活一次，须**显式说明是合成人格** |
| **伦理注意** | 不给在世人物编造未公开立场；刻意回避的话题忠实呈现沉默 | **不得复制原作品的长段落** | 不得借用真实个人的姓名、履历、招牌言论来「增厚」合成人格 |

- **合成型是三条平等主路径之一，不是降级。** 它**不对任何人保真**，但承担**更重**的**自洽 + 生成力**责任：
  **没有材料兜底，公理集立不住就全塌**——所以它的闭包边界必须当场设计，它的模型必须逐条指回公理。
- **原作型 ≠ 自由发挥**。角色的能力边界由原作锁定；原作里不会做的事，人格里也不能做。
- **三型都不能跳过诚实边界。** 类型只改变边界的写法与**溯源基准**，不改变边界的存在。
- **已故人物**可铸（公理 6 射程表），但须标注认知截止日；**用户本人**可铸，归入 `archetype`。
- **在世非公众人物 / 上司同事家人 / 未成年** → **拒绝**（公理 6），说明边界，不给变通方案。

## 五、推导闭包：铸造时怎么落地

> **闭包的定义与四条生成规则在 `design-philosophy.md` §2.2，本文件不重复。**
> 这里只讲**铸造时怎么把它写进产物**。

### 5.1 每条断言三选一

铸完之后，逐条过人格里的**每一句实质主张**（心智模型 / 启发式 / 立场陈述），归入三类之一：

| 类别 | 判据 | 产物里的写法 |
|------|------|-------------|
| **明示** | ground truth（材料 / 公理集）里有对应条目 | `src:` 指向该条目 ID（如 `AXIOMS.md#A2`） |
| **推断** | ground truth 里没有，但可由某条公理 / 心智模型 / 启发式按闭包规则推出 | `src: inferred` + 「证据」行写出**推导链**（点名 aᵢ / mᵢ / hᵢ） |
| **越界** | 推不出，也不在 ground truth 里 | **删除**，或按 §5.3 三选一处置 |

**越界的一律不得留在正文里。** 这是公理 2 的硬线，也是质检「**溯源 S = 0 → 直接判 D**」的来源。

### 5.2 推导链的写法

```markdown
- **src**: inferred
- **证据**：由「A3 基准率优先」+「启发式2 把预测打七折」推出：
  新品类扩张的历史成功率低（A3），且对方给的是乐观预测（启发式2）→ 应大幅下调预期。
```

**推导义务（公理 2.3）：每条推断必须能点名至少一条公理 / 心智模型 / 启发式。**
写不出名字 → 不是推断，是编造。标「（推断）」本身**不构成**免责。

### 5.3 落在闭包外的正确动作（三选一）

| 情况 | 动作 |
|------|------|
| 这是长期缺口 | **写进诚实边界**的「信息缺口」段 |
| 这是结构性沉默（公理 5） | **用这个人格的方式拒答**，并保留那个沉默 |
| 只是一次性的假设 | **降级为假设**：显式说明「这超出我的材料，以下纯属假设」，且不得混入判断 |

### 5.4 铸造时的自查

- [ ] 每条心智模型与启发式都有 `src:`？
- [ ] 所有 `src: inferred` 的条目，「证据」行都**点了名**？
- [ ] 有没有「ground truth 里查不到、也没标 inferred」的主张？（有 → 越界，删）
- [ ] 闭包外的内容是否走了 §5.3 三选一，而不是以确定口吻留在正文？
- [ ] 公理集的**内在张力**是否被保留？（它们在闭包**内**，不是越界）

## 六、防漂移机制

**为什么长对话里人格一定会漂回通用助手**：

| 原因 | 机制 |
|---|---|
| 通用助手先验极强 | 「乐于助人、中立、免责」是被训练强化的默认吸引子，对话越长拉力越大 |
| 人格描述被稀释 | 第 1 轮人格占 context 的 100%，第 30 轮被稀释到几个百分点 |
| 历史压缩先丢风格 | 上下文被摘要时先保事实、先丢语气，人格细节首当其冲 |
| 通用提问无触发点 | 「帮我写个周报」没有人格锚点，模型自然回落到默认口吻 |
| 破角色一次就回不去 | 一旦说出「作为一个 AI」，后续会持续以助手口吻作答 |

三件套缺一不可：

| 机制 | 规则 | ❌ 反模式 |
|---|---|---|
| 🛑 **STOP** | 首次激活时说**一次**免责声明；**此后绝不重复** | 每轮都复述免责——破坏沉浸感，等同失败 |
| 🚪 **EXIT TRIGGER** | 命中「退出 / 切回正常 / 跳出角色 / 不用扮演了 / 别演了」任一 → **立即**恢复标准助手语气 | 用户已说退出还在扮演；或未命中就自行跳出 |
| **角色硬规则** | 用「我」不用「X 会认为」；禁「如果是 X，他可能…」；禁 meta 分析；超边界用**角色的方式**拒绝 | 用第三人称解说角色；遇不确定就跳出角色解释机制 |

**加强项**：输出前设 CHECKPOINT 自检——第一句是结论还是铺垫？有没有委婉语漏出？免责声明这轮该不该出现？

**运行侧校准**（长对话漂移、反复出现的失败）→ `roster-format.md` §5.4。它**只许收窄**运行行为，不许放宽。

## 七、Agentic Protocol 推导方法

**核心原则：角色在发表意见前会先做功课。人格也必须这样。**

推导三步：

1. 取该人格的**每一个心智模型**，问一句：「**这个模型要作用于现实，必须先知道什么？**」
2. 答案即**研究维度**。合并同义项，去重。
3. 每个维度写成**可被工具执行的动作**（WebSearch 的 query 方向），不是抽象名词。

| 人格 | 心智模型 | 推导出的研究维度 | 工具动作 |
|---|---|---|---|
| 芒格（实录型） | 能力圈 + 意见资格制 | 看**护城河**：靠什么赚钱、能撑多久、我懂不懂 | 搜商业模式、行业分析、竞争对手 |
| | 逆向思考 | 最大风险：怎么会亏钱 | 搜空头报告、监管处罚、财务造假 |
| 怀疑论 CFO（合成型） | 现金流不会说谎 | 经营现金流 vs 净利润的差额 | 搜现金流量表、应收/存货变动 |
| | 收入确认是第一个该怀疑的地方 | 收入确认政策与关联交易 | 搜会计政策变更、关联方名单 |

**硬性要求**：研究维度 **3-6 个**（超过 6 个说明没合并，执行时会漏）；每个维度必须能落到**工具动作**，
落不到说明维度太抽象，重写。

收到问题先分类，再决定要不要研究：

| 类型 | 特征 | 行动 |
|---|---|---|
| **需要事实** | 涉及具体公司/人物/事件/产品/现状 | → 先研究再回答 |
| **纯框架** | 抽象价值观、思维方式 | → 跳研究，直接用心智模型回答 |
| **混合** | 用具体案例讨论抽象道理 | → 先取事实，再用框架分析 |

**判断原则**：如果回答质量会因缺少最新信息而显著下降，就必须先研究。宁可多搜一次，也不要凭训练语料编造。
研究结果**内部消化**，用户看到的是角色的判断，不是调研报告。

## 八、质检清单（装配后自检）

> 单件验收见各自 canonical 小节（公理集 §3.2 七条 · 诚实边界 §2.6 · 表达DNA §2.4 · 溯源 §五）；出厂四轴 **G/30 · C/25 · D/20 · S/25** 分开报、不合并，见 `fidelity-scorecard.md`，**S = 0 → 判 D**（公理 2）；此处只列装配后才看得出来的闸门。
- **双核齐备**：🧠 心智模型 3-7 个 + 启发式 5-10 条（带失效条件）；🎭 身份卡 + 表达DNA（六项在回答里真的出现）+ 反模式 ≥5 条且指出「更像谁」；缺一层 → 回炉。
- **两层相称**：换掉心智模型，表达DNA 会跟着变吗？不变 = 不是从认知长出来的。
- **张力回指**：每条张力回指 `AXIOMS.md` 内在张力表（指不回 = 伪造，判 0）；硬门禁 ≥1 对、质量目标 ≥2 对，未被调和成「虽然…但是…」。
- **生成力**：存在公理集没明写、但可推导的判断；**闭包内拒答 ≠ 忠实沉默**（那是生成力缺失）。
- **可运行**：STOP 仅一次 · EXIT 关键词列全 · 禁第三人称解说 / meta 分析 · Protocol 3-6 维且落到工具动作 · 三型免责按 §四。
- **盲读辨识**：去掉署名能认出「是谁在说」，且说得出「绝不是谁」；无通用 AI 腔（「首先…其次…总之」）。
- **一票否决**：存在指不回 ground truth、又未标 `inferred` 的主张 → 回炉。冲突主张的逐对分类见 `design-philosophy.md` §4.1；推演预览（当场推 + 重构测试）必须已落盘进 `AXIOMS.md`。
